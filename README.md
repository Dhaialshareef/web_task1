# web_task1


1. Designing the Web Page to Display the Model:
Create an HTML Page with a simple interface.
Add a file input field to accept images using <input type="file">.
Display the uploaded image using the <img> tag.
2. Integrating the Trained Model:
Use the model links extracted from Teachable Machine (e.g., model.json and metadata.json).
Include JavaScript code to process the image using TensorFlow.js.
3. Enable Database Connection:
Connect to Firebase Realtime Database.
Write code to automatically update the database whenever a prediction is made.
4. Create a Prediction Counter:
Create a key in the database to store the count of predictions.
Increment the counter in the database after each prediction.
5. Display the Counter on the Page:
Add a <span> element on the page to show the counter value.
Write code to fetch the counter value from the database and display it.
6. Add a Reset Button for the Counter:
Design a button that resets the counter value to zero when clicked.
